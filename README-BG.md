# MMA.bg Product Robot — Vercel версия

Това е тестова Vercel версия на първия продуктови робот.

## Най-лесно качване

1. Разархивирай ZIP-а.
2. Качи цялата папка в нов GitHub repository.
3. Влез във Vercel → Add New → Project.
4. Избери repository-то.
5. Натисни Deploy. Не е нужен VPS и не е нужен build command.
6. Отвори дадения от Vercel адрес.

## Тест

На началната страница има два бутона:
- „Намери продуктите“ — проверява категорията в mma.bg.
- „Изтегли 5 продукта“ — чете 5 реални продуктови страници.

API:
- `/api` — статус
- `/api/discover` — намира URL адресите на продуктите
- `/api/product?url=...` — чете един продукт
- `/api/sync?limit=10&offset=0&persist=0` — чете пакет продукти
- `/api/cron` — автоматично изпълнение

## База — по желание

За първия тест не ти трябва база.

Когато искаме продуктите да се запазват и да сравняваме стари/нови цени:
1. Създаваме Supabase проект.
2. Пускаме `sql/supabase.sql` в SQL Editor.
3. Във Vercel → Settings → Environment Variables добавяме:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
4. Redeploy.

След това `/api/sync` автоматично записва/обновява продуктите.

## Автоматична проверка

`vercel.json` съдържа cron веднъж дневно за теста. Vercel Hobby позволява cron само веднъж дневно. За по-чести проверки ще използваме друг scheduler или платен Vercel план, а при нормален хостинг може да използваме cron от хостинга.

## Важно

Vercel функцията не пази надеждно локален SQLite файл между изпълненията. Затова тази версия не използва SQLite.
